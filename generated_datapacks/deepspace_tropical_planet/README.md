# Deep Space Tropical Planet

此数据包为 Deep Space 添加行星 `Tropica`：

- 目标维度：`tropicraft:tropics`
- 纹理：未指定，由 Deep Space 动态生成
- 大气：与主世界行星相同，白色、缩放 `1.1`
- 位置：Pelagos 外侧，中心约为 `(0, 200, 3000)`

## 安装

1. 确保当前实例安装了 Tropicraft 和支持数据包行星定义的新版 Deep Space。
2. 将整个 `deepspace_tropical_planet` 文件夹放入目标存档的 `datapacks` 文件夹。
3. 重新进入存档，或在已进入存档时执行 `/reload`。
4. 执行 `/planets list`，确认列表中出现 `Tropica (tropica)`。

移除时退出存档，删除该数据包文件夹后重新进入存档。
